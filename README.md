## 🧐 Project Overview

This repo provides tools and scripts to:
- Read movie rating data (CSV/JSON),
- Clean & preprocess movie metadata,
- Compute descriptive statistics (e.g. average rating, number of reviews),
- Produce insightful visualizations (histograms, scatter plots, trends over time),
- Easily extendable to support additional datasets or metrics.

---

## ⚙️ Features

- Load datasets using **pandas**
- Clean & normalize data (handle missing values, types)
- Aggregate statistics by genre, year, director, etc.
- Generate visualizations with **matplotlib** and **seaborn**
- Support for interactivity or dashboard extension
